# Models Directory

Place your model files here:
- Supported formats: .gguf, .bin
- Examples: llama-2-7b-chat.gguf, mistral-7b-instruct-v0.1.bin
- Ensure models are compatible with llama.cpp

## Download Models

You can download models from:
- Hugging Face: https://huggingface.co/
- TheBloke's models: https://huggingface.co/TheBloke
- llama.cpp models: https://github.com/ggml-org/llama.cpp#obtaining-and-using-the-facebook-llama-2-models

## Model Naming Convention

Format: {model_name}-{size}b-{type}.{extension}
Examples:
- llama-2-7b-chat.gguf
- mistral-7b-instruct-v0.1.bin
- codellama-13b-python.gguf
